## ДЗ №3. Основы Matplotlib
**Тема:** архитектура Matplotlib, Figure/Axes

## Задание
В файле задания скрипт task3-4/odu_solver.py, решающий нелинейное уравнение движения физического маятника двумя численными методами — явным методом Эйлера и методом Рунге—Кутты 4-го порядка (RK4) — с разным шагом по времени `h`. Надо  **визуализировать результаты и проанализировать сходимость методов**

**Часть A. Базовые траектории**

1. На одном графике постройте `θ(t)` и `ω(t)` (можно на двух `Axes` одной `Figure`) для RK4 с мелким шагом — это будет эталонное решение.

2. Постройте **фазовый портрет** маятника (`θ` по оси X, `ω` по оси Y) как линию; поверх — `scatter` с редкими маркерами, показывающими положение системы через равные промежутки времени. Аннотацией (`ax.annotate` со стрелкой) отметьте начальную точку и направление движения по траектории.

3. На отдельном графике наложите: эталонное решение RK4 (гладкая линия) и решение Эйлером с крупным шагом (`h = 0.2`) — **точками (scatter)**, чтобы показать, как теряется точность при большом шаге.

**Часть B. Анализ сходимости**

4. Возьмите набор шагов `h`, уменьшающихся в 2 раза: например `h = 0.2, 0.1, 0.05, 0.025, 0.0125, ...`.

5. Для каждого `h` посчитайте решение методом Эйлера и методом RK4, сравните с эталонным решением (RK4 с очень мелким шагом) в фиксированный момент времени `T` и вычислите ошибку `err(h) = |θ_h(T) − θ_ref(T)|`.

6. Постройте график `err(h)` от `h` для обоих методов на **логарифмических осях** с минорной сеткой.

7. С помощью `np.polyfit` на данных в логарифмических координатах (`log(err)` от `log(h)`) оцените **порядок сходимости** каждого метода (наклон прямой) .Подпишите полученный порядок прямо на графике (`ax.annotate` или `ax.text`), например `"порядок ≈ 3.98"`.

8. Добавьте заголовок, подписи осей (с указанием, что это именно `h` и ошибка), легенду, различающую методы, и примените один из стилей оформления (`plt.style.use(...)`).

**Часть C. Энергия**

9. **Bar chart.** Для фиксированного `h` постройте столбчатую диаграмму относительного изменения полной энергии `|E(T) − E(0)| / E(0)` для Эйлера и для RK4.

10. **Pie chart.** Для одного момента времени постройте круговую диаграмму соотношения кинетической и потенциальной энергии маятника (`KE`, `PE`), сумма которых равна полной энергии.
